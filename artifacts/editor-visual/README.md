# Editor visual verification

Playwright regenerates these retained Chromium artifacts from the rendered documentation mock and production Editor at identical viewports. Each state includes the reference, production, pixel difference, side-by-side review, and difference summary.

The required states cover Structured content, collapsed Source, Source with Quick Add, Layout with hovered bounds, expanded filtered diagnostics, and desktop/two-pane/single-column responsive layouts. The HTML Playwright report also carries the corresponding per-browser attachments.
