Accepted onboarding design

Modern welcome tour

A first-run, resumable spotlight lesson that teaches navigation before actions, uses isolated practice data, and ends with an explicit interface-presentation choice.

Interaction contract

Navigate visibly

Tabs, explorer rows, pages, and disclosures are user-completed steps. A controlled directive prepares a view only for recovery, Back, Skip, or reload.

Reveal the result

Context-changing actions retarget the completed coachmark around their result before Continue advances. Inventory navigation is followed by a dedicated reveal of Field Training and Traveler’s Pack.

Stay temporary

The practice Editor workspace and Tracker chain live only in the validated tour-session aggregate and never enter normal registries.

Remain in context

A translucent four-region scrim preserves spatial orientation. The highlighted target retains shape, focus, and non-color boundaries.

Lifecycle and persistence

ApplicationSettings schema 5 stores onboarding.welcomeTourStatus as pending, in-progress, completed, or dismissed. New installs are pending; earlier settings schemas hydrate as dismissed so established users are not interrupted.

WelcomeTourSessionV1 stores the current step, branch progress, return path, exact Editor and Tracker input, navigation outcomes, revision, and rollback checkpoints. Browser IndexedDB and bounded Tauri commands validate expected fixture IDs, files, packages, step IDs, and size. Browser writes use a revisioned synchronous pending mirror so an immediate reload cannot outrun the durable transaction.

Completion and dismissal both require the non-dismissible interface picker and then clear the session. A Settings restart preserves the underlying return route and explicit-save departure guard. “Keep my current settings” is available only for a restarted tour.

Accessibility and internationalization

  • The coachmark and highlighted target form one focus cycle; unrelated controls remain pointer- and keyboard-inert behind the four-region scrim.
  • The target receives aria-describedby, headings receive programmatic focus, success and step changes are announced, and Escape opens the Exit outcome instead of silently dismissing.
  • Target rings combine shape, border, glow, and contrast rather than color alone. High-contrast mode strengthens the border; the resolved Reduced Motion setting removes spotlight spatial interpolation.
  • Editor, Tracker, Beginner friendly, and Advanced choice icons use a white tile with accessible accent glyph and border colors in Light mode; Dark mode retains its established dark accent tile.
  • Placement tracks ResizeObserver, nested scrolling, browser zoom, viewport resizing, RTL direction, and target replacement. Missing targets show Retry and Skip recovery.
  • Every heading, instruction, action, announcement, mode description, and fixture display value is localized through the standard English-fallback catalog. Stable handles and IDs are intentionally not translated.
